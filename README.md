## <p align="center">yijing</p>

### An interactive representation of the I Ching (Easy Changes)
made with ReactJS featuring <a link="https://github.com/Liu-Jinshuai/moon-time">`moon-time`</a>, an API used to convert the current or specified Gregorian date and time(between the years 2000 and 2100) to the Chinese Lunisolar equivalent which is then calculated using Shao Yung's Five Plum Numerology method to generate three hexagrams.
